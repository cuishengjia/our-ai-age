# raw/

**原始源材料层（immutable sources）。**

这里放用户 curate 的源：

- 文章、paper、podcast 笔记
- 用户口述的实践经验（第一人称，待 ingest）
- 外来文档、截图、PDF 等

## LLM 权限

- ✅ 读取并在 [`../wiki/`](../wiki/) 中综合、引用、回链。
- ❌ 修改、删除、重命名现有文件。

## 约定

- 文件命名用 kebab-case slug，英文或中文皆可。
- 结构自由，可带子目录（按来源或话题分组）。
- 资源文件（图片、PDF）建议放 `raw/assets/`。
